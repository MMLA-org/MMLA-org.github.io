MMLAv4

记忆介导学习架构Memory-Mediated Learning Architecture

预测式双状态适应Predictive Dual-State Adaptation

MMLA 为模型设计了两种有界状态：策略状态 Φ 根据同一问题内的反馈更新，记忆 M 保存已完成片段中的信息。v4 讨论这两种状态如何分别更新，并供后续推理共同使用。 MMLA proposes two bounded states for reasoning. Policy state Φ adapts to feedback within a problem; memory M stores information from completed segments. v4 defines how they are updated separately and used in later reasoning.

01 / 系统架构Architecture

策略更新与记忆管理Policy updates and memory management

策略和记忆各自维护版本、写入权限与回滚记录。一次推理读取兼容的版本组合，更新后的状态用于之后的推理。Policy and memory have separate versions, write permissions, and rollback records. Each attempt reads a compatible pair; updates become available to later attempts.

01

问题内的策略更新Policy adaptation within a problem

同一问题求解期间，反馈可以触发一次有界更新，也可以保持策略状态不变。后续尝试读取更新后的策略。While a problem is being solved, feedback may trigger a bounded policy update or leave the state unchanged. Later attempts read the updated policy.

02

片段结束后的记忆写入Memory updates after a segment ends

片段结束后，系统按顺序处理其中的事件。每次替换一条完整记忆行，或执行 NULL，保留原状态。Once a segment ends, its events are processed in order. Each event replaces one complete memory row or takes the NULL action, preserving the existing state.

03

训练时的未来监督Future outcomes as training signals

训练时，同一历史之后的多个分支用于估计写入动作的价值。部署时只使用当时已有的信息。During training, multiple continuations of the same history are used to estimate the value of memory actions. Deployment uses only information already available.

03 / 研究局限Limitations

尚待验证的问题Open questions

现有实验主要检验受控任务中的单个组件。自然语言记忆管理和完整 PDSA 的效果仍需验证；论文中的定理也依赖各自的假设条件。截至 v4，以下问题尚无实验证据支持：The experiments test individual components under controlled conditions. Natural-language memory management and full PDSA performance remain unverified, and the theorems depend on their stated assumptions. v4 leaves three empirical questions open:

  • 排除上下文和记忆的影响后，策略更新能否改善同一问题的后续推理（RTT）。Whether policy updates improve later attempts on the same problem after controlling for context and memory (RTT).
  • 使用未来信息的记忆准入 oracle 能否优于基线，以及只使用历史信息的策略能否学到这一优势。Whether a memory-admission oracle using future outcomes can outperform the baselines, and whether a policy using only history can learn that advantage.
  • 同时更新策略和记忆，能否产生超出两者独立效果之和的收益。Whether updating policy and memory together produces a benefit beyond the sum of their individual effects.

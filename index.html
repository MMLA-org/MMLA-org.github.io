记忆介导学习架构Memory-Mediated
Learning Architecture

预测式双状态适应Predictive Dual-State Adaptation

一次问题求解尚未结束，模型能否根据反馈调整后续推理？MMLA 提出两种独立、有界的适应状态：Φ 调整策略，M 保存记忆。两者分别更新，共同作用于后续尝试。 Can a model use feedback to adapt before a problem is finished? MMLA proposes two independent, bounded states: Φ adapts the policy; M retains memory. Each is updated separately, and both inform later attempts.

01 / 运行机制Mechanisms

两种状态，一次推理循环Two states. One reasoning loop.

策略决定如何利用信息，记忆决定保留哪些信息。它们在不同的时机更新。Policy shapes how information is used. Memory determines what is retained. They change at different points in the loop.

Φ

POLICY STATE

调整后续推理的方式Adapt how to reason

有界的数值载体。在同一问题内，收到反馈后更新。A bounded numerical carrier, updated from feedback within the same problem.

M

AUTHORITATIVE MEMORY

保留后续需要的信息Retain what may be needed

固定容量的完整记忆行。片段结束后，逐事件决定是否写入。Complete rows in a fixed capacity. After a segment ends, each event may lead to a write.

一次尝试开始时At the start of an attempt

先读已有状态，
再生成下一步。Read the current states.
Then reason forward.

模型读取一组兼容的策略与记忆版本，再基于已经看到的内容进行推理。这次尝试使用固定的版本组合。The model reads compatible versions of policy and memory, then reasons from what it has already observed. That pair stays fixed for the attempt.

读取边界Read boundary未来的答案、反馈和评估结果不在输入中。Future answers, feedback, and evaluation results are unavailable.

同一问题仍在求解中While the same problem is being solved

反馈到达后，
策略可以改变。New feedback can
change the policy.

已完成尝试的反馈可以触发对 Φ 的有界更新，也可以不更新。新的 Φ 供后续尝试读取，无需等到整道问题结束。Feedback from a completed attempt may trigger a bounded update to Φ, or no update. Later attempts can use the new Φ before the whole problem ends.

独立更新Separate updates更新 Φ 不等于改写记忆 M，也不等于在线改写基础参数 θ。Updating Φ does not rewrite memory M or the base parameters θ.

片段完成之后After a segment ends

把已发生的内容，
整理成候选记忆。Turn completed events
into memory candidates.

系统回看已完成片段，按顺序处理事件。神经模型针对各可行槽位提出内容，可信模块组装完整候选行，再校验字段和写入权限。The system reviews the completed segment and processes its events in order. A neural model proposes content for each feasible slot; a trusted module assembles and validates the complete candidate rows.

提交边界Commit boundary生成候选内容并不直接改变权威记忆。Proposing content does not itself change authoritative memory.

每个事件的写入决策The decision for each event

提交完整一行，
或者保持原样。Commit one full row.
Or change nothing.

控制器从可行槽位和 NULL 中选择。一次事件最多替换一行，后一个事件读取前一个事件处理后的记忆；所有事件处理完，再供后续推理使用。The controller chooses a feasible slot or NULL. Each event replaces at most one row; the next event reads the resulting memory. Later reasoning reads it after all events are processed.

容量与回滚Capacity & rollback记忆容量不增长。Φ 与 M 分别维护版本和恢复记录。Memory capacity stays fixed. Φ and M keep separate versions and restore records.

预测式记忆准入Predictive memory admission

这条记忆，
以后用得上吗？Will this memory
help later?

刚出现的信息未必值得保留。准入的目标，是比较“写入某个槽位”和“不写入”对后续任务的预期影响，并计入存储与更新成本。Recent information is not always worth keeping. Admission aims to compare the expected effect of writing to a slot against writing nothing, including storage and update costs.

02 / 系统架构Architecture

把两条路径放回完整架构The two paths in the full architecture

策略和记忆各自维护版本、写入权限与回滚记录。一次推理读取兼容的版本组合，更新后的状态用于之后的推理。Policy and memory have separate versions, write permissions, and rollback records. Each attempt reads a compatible pair; updates become available to later attempts.

当前生成过程的工作状态，随 token 和尝试变化。它与跨片段保留的记忆 M 有不同的生命周期。The working state of generation changes across tokens and attempts. Its lifetime differs from memory M, which persists across segments.

片段工作区Segment workspace

汇总片段内已经发生的信息，容量有界。片段结束后，系统据此构造记忆候选。A bounded summary of information observed within a segment. After the segment ends, it supports the construction of memory candidates.

θ

慢变基础参数Slow base parameters

在预训练或离线训练中更新，与推理时可变的 Φ、M 分开管理。Updated during pretraining or offline training, and managed separately from Φ and M, which can change during reasoning.

04 / 研究局限Limitations

尚待验证的问题Open questions

现有实验主要检验受控任务中的单个组件。自然语言记忆管理和完整 PDSA 的效果仍需验证；论文中的定理也依赖各自的假设条件。截至 v4，以下问题尚无实验证据支持：The experiments test individual components under controlled conditions. Natural-language memory management and full PDSA performance remain unverified, and the theorems depend on their stated assumptions. v4 leaves three empirical questions open:

  • 排除上下文和记忆的影响后，策略更新能否改善同一问题的后续推理（RTT）。Whether policy updates improve later attempts on the same problem after controlling for context and memory (RTT).
  • 使用未来信息的记忆准入 oracle 能否优于基线，以及只使用历史信息的策略能否学到这一优势。Whether a memory-admission oracle using future outcomes can outperform the baselines, and whether a policy using only history can learn that advantage.
  • 同时更新策略和记忆，能否产生超出两者独立效果之和的收益。Whether updating policy and memory together produces a benefit beyond the sum of their individual effects.

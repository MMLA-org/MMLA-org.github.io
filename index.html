what matters

MMLA 是一套给 AI 用的记忆规则：先完成当前回答，再决定什么值得留下。它不会改写已经说过的话；每次要么完整更新一条记忆，要么什么也不改。 MMLA is a set of memory rules for AI: finish the current answer first, then decide what is worth keeping. It never rewrites what was already said; each update either replaces one complete memory or changes nothing.

01 / 为什么是记忆WHY MEMORY

AI 不需要记住一切，
只需要记住以后有用的事。 AI need not remember everything.
It needs what will help later.

MMLA 把一次已经完成的经历，整理成少量可更新的“工作笔记”。每次保存前，它都会先问：这件事以后有用吗？该更新哪一条？没有把握时，能不能先不动？ MMLA turns a finished experience into a small set of editable working notes. Before saving, it asks: will this help later, which note should change, and should we leave things alone when unsure?

它不是无限长的聊天记录，也不是重新训练模型。它更像一份有限的笔记：可以查看、更新和撤回，但不会无限增长。 It is neither an endless chat log nor model retraining. It is a limited notebook: inspectable, editable, and reversible, without growing forever.

可以这样理解：当前上下文像桌上的草稿，模型参数像长期养成的习惯，MMLA 记忆像一本有限的工作笔记。草稿不一定要记进笔记；不可靠的信息也应该留在外面。 Think of context as notes on a desk, model weights as long-term habits, and MMLA memory as a small working notebook. Drafts and unreliable information do not have to enter that notebook.

“

记忆是为了帮下一次回答，不是为了篡改上一次回答。 Memory should help the next answer, not rewrite the last one.

02 / 它是怎样工作的HOW IT WORKS

先完成当前任务，
再决定要不要更新记忆。 Finish the current task.
Then decide whether memory should change.

流程很简单：先回答，再等这一小段任务结束；然后准备可能的更新，检查它们是否可靠，最后更新一条完整记忆，或者保持原样。新记忆只会帮助之后的回答。 The flow is simple: answer first, wait for this task segment to end, prepare possible updates, check that they are safe, then update one complete memory or keep everything as is. New memory helps only later answers.

什么算正式记忆WHAT COUNTS AS SAVED MEMORY

如果一处内容会影响以后系统能读到什么、能不能访问或怎样更新，它就是正式记忆。搜索结果和缓存可以重建，但不能代替正式记录。If a piece of state affects what the system can later read, access, or update, it is saved memory. Search results and caches can be rebuilt, but they cannot replace the official record.

一条记忆里有什么WHAT ONE MEMORY CONTAINS

除了内容，还要有身份、版本、访问范围、来源、是否删除，以及怎样撤回等信息。它们要一起保存，才能追溯和检查。Alongside content, it carries identity, version, access scope, source, deletion status, and rollback details. They are saved together so the record can be checked and traced.

谁能写什么WHO WRITES WHAT

模型提出要记住的内容和修改建议；系统负责身份、权限、版本和撤回信息。最后只能完整替换一条，或者什么也不改。The model proposes content and an edit; the system controls identity, access, version, and rollback details. The result is either one complete replacement or no change.

哪些东西要分开WHAT STAYS SEPARATE

当前对话、保存的记忆、可重建的搜索索引、外部历史记录，以及模型或策略状态，不能混为一谈。记忆数量有限，不代表外部历史可以无限免费保存。Current conversation, saved memory, rebuildable search indexes, external history, and model or strategy state must stay separate. Bounded memory does not make unlimited external history free.

更新可能帮助以后，也可能带来过时信息、挤掉旧记忆和额外成本。新内容和它要替换的旧内容，必须一起判断。An update may help later, but it can also introduce stale information, displace a useful note, and add cost. New content and the note it replaces must be judged together.

训练和真实使用的区别TRAINING VS. LIVE USE

训练时可以根据后来的结果比较不同选择；真实使用时只能看当时的信息。不能先知道未来，再倒过来挑一个最好的更新。Training may compare choices using later outcomes; live use can rely only on information available then. It cannot see the future and choose an update afterward.

论文完成的理论工作WHAT THE PAPER ESTABLISHES

  • 把训练时能知道的后来结果，和真实使用时只能做的预测分开。Separates later outcomes available in training from predictions available in live use.
  • 说明在条件满足时，系统可以稳定找出更好的选择，并量化判断有误时会付出多大代价。Shows that, under stated conditions, the system can stably identify better choices and quantify the cost of judgment error.
  • 给出保守规则：不确定时，优先不改；也说明数据变化和判断误差会怎样增加风险。Provides a conservative rule: when uncertain, do not change memory, and explains how data shift and judgment error raise risk.
什么会让它不可靠WHAT MAKES IT UNRELIABLE

如果用更新之后才知道的信息给更新打分、训练数据没见过某种选择，或几个选择差别小到无法判断，结论就会变得不可靠。The result becomes unreliable if updates are scored with information learned afterward, training data lacks a choice, or choices are too close to distinguish.

它没有证明WHAT IT DOES NOT PROVE

它没有说系统已经学会可靠地自动更新，也没有说更新通常比不更新好。它提供的是一套遇到不确定性会退回原样的判断方法。It does not say the system has already learned reliable automatic updates or that updating is usually better. It provides a decision method that falls back to no change under uncertainty.

MMLA–RTT Dual State

两条线：下次怎么回答，和下次能读什么，要分开记录Two separate lines: how the next answer acts and what it can read

它把答题策略 Φ 和保存的记忆 M 分开，避免把“换了做法”和“多了一条笔记”当成同一件事。It separates answer strategy Φ from saved memory M, so a changed approach is not confused with an added note.

Φ / 答题策略ANSWER STRATEGY

它决定下一次尝试会怎样行动，例如更偏向哪种解题方法。它由反馈驱动的训练来更新，有自己的版本和撤回方式。It affects how the next attempt acts, such as which solving approach it favors. Feedback-driven training updates it, with its own versions and rollback path.

M / 保存的记忆SAVED MEMORY

它决定下一次可以读到什么。它数量有限、带版本和来源，只能通过完整记录来更新。It determines what the next attempt can read. It is limited, versioned, sourced, and updated only through complete records.

一次尝试怎样使用它们HOW AN ATTEMPT USES THEM

一次尝试固定使用某个策略版本和某个记忆版本，避免回答做到一半发生漂移。但固定一起使用，不等于它们变成同一种东西。One attempt uses a fixed strategy version and memory version so it does not drift midway through an answer. Using them together does not make them the same thing.

论文完成的理论工作WHAT THE PAPER ESTABLISHES

  • 为策略和记忆分别规定谁能更新、谁能读取、如何重置和如何撤回；只改记忆不算训练策略。Defines separate writers, readers, resets, and rollback for strategy and memory; changing memory alone is not strategy training.
  • 说明两者如何分别回退，以及什么情况下它们可以安全地一起使用。Explains how each can roll back independently and when they can safely work together.
  • 给出四组对照：改策略或不改、改记忆或不改，用来分辨各自带来的影响。Defines four comparisons: strategy on or off, memory on or off, to separate their effects.
什么时候能说“真的在学习”WHEN CAN WE SAY IT LEARNED?

只有反馈真的改变了策略 Φ，改变发生在同一道题结束前，而且后一次新的尝试读到了新策略，才可以说发生了严格的推理时训练。只改记忆不能替代这条证据。Only when feedback changes strategy Φ before the same problem ends and a fresh later attempt reads it can we claim strict reasoning-time training. Changing memory alone is not enough.

它没有证明WHAT IT DOES NOT PROVE

分清两类状态，不等于系统已经更好。没有版本和读写记录，就不能从“答案变好了”判断到底是哪一部分带来的改变。Separating the two states does not itself improve the system. Without version and read/write records, a better answer cannot show which part caused the change.

下一次新尝试用到了这个变化A FRESH LATER ATTEMPT USES THE CHANGE

不是继续同一条回答，而是一次新尝试读取更新后的版本。It is not a continuation of the same answer, but a fresh attempt that reads the updated version.

它排除哪些误会WHAT IT RULES OUT

多搜索几次、上下文变长、只改记忆、多给一点算力或碰巧抽到更好的答案，都可能让后一次更好，但不等于系统真的在同一道题里学了。More search, longer context, memory-only edits, extra compute, or a luckier sample can improve a later attempt without proving that the system learned within the same problem.

不能把变化藏起来CHANGES CANNOT BE HIDDEN

如果后续回答还读取了其他发生变化的状态，就不能只把功劳算给 Φ。需要把所有真正影响回答的变化一起说明。If later answers read other changed state, credit cannot go to Φ alone. Every change that truly affects the answer must be accounted for.

需要哪些证据EVIDENCE NEEDED

需要记录尝试、反馈、更新什么时候开始和结束、读了哪个版本，以及什么时候重置或停止。只看输入和输出，分不清到底是学习、搜索还是记忆变化。Record attempts, feedback, when updates start and finish, which version was read, and when the system resets or stops. Inputs and outputs alone cannot separate learning from search or memory changes.

论文完成的理论工作WHAT THE PAPER ESTABLISHES

  • 说明相同的外在表现可能来自不同的内部过程，所以只看最后答案不能证明学习。Shows that the same visible behavior can come from different internal processes, so the final answer alone cannot prove learning.
  • 给出对照方法，例如随机开关策略更新、重置后比较结果。Provides comparisons such as randomly turning strategy updates on or off and comparing after reset.
  • 规定策略变化、撤回和停止条件，让题内学习也受资源和安全限制。Sets conditions for strategy change, rollback, and stopping so within-problem learning stays resource- and safety-bounded.
它和 MMLA 有什么关系HOW IT RELATES TO MMLA

RTT 是判断“是否真的在学习”的额外标准，不是记忆更新的必经步骤。MMLA 可以只更新有限记忆，而不宣称发生了 RTT。RTT is an additional test for whether learning really occurred, not a required memory-update step. MMLA can update limited memory without claiming RTT.

它没有证明WHAT IT DOES NOT PROVE

这篇没有报告新的性能优势，也没有说满足定义就一定更准确。它做的是把定义、对照方法和安全边界说清楚。This paper reports no new performance advantage and does not say that meeting the definition guarantees accuracy. It clarifies the definition, comparisons, and safety boundaries.
